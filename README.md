**Cara install dan setup environment**

1. Clone repository: git clone https://github.com/Oktarezapramudya/simplecrm.git
2. Install dependensi: npm install
3. Buat file .env untuk environment variables
4. Setup database di PostgreSQL dengan tabel pelanggan

**Cara menjalankan aplikasi**
1. Jalankan aplikasi: node app.js
2. Buka browser: http://localhost:3000
